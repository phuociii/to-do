Lịch sử quay

    🍎 Lịch Apple (iCloud)

    Dán link lịch công khai (bắt đầu bằng webcal:// hoặc https://). Có thể thêm nhiều lịch.

      Cách lấy link lịch trên iPhone / Mac
      1. iPhone: mở app Lịch → chạm Lịch ở dưới → chạm nút ⓘ cạnh lịch muốn dùng → bật Lịch công khai → Chia sẻ liên kết… → Sao chép. Dán vào ô trên.
      2. Mac: app Lịch → chuột phải vào lịch (cột trái) → Chia sẻ lịch… → tích Lịch công khai → bấm biểu tượng chia sẻ → Sao chép.
      3. Lịch “Trên máy iPhone” hoặc lịch Google/Exchange không có nút này — hãy dùng lịch iCloud, hoặc dán link .ics của dịch vụ đó (Google Calendar có “Địa chỉ bí mật ở định dạng iCal”).
      4. Link công khai: ai có link đều xem được lịch. Đừng chia sẻ link này.

      🔐 Đồng bộ qua GitHub (ổn định nhất)

      GitHub tự tải lịch của bạn mỗi 30 phút, mã hoá AES-256 rồi đưa lên web. Không cần proxy công cộng, chỉ ai có mật khẩu mới đọc được.

      1. Mở trang tạo secret trên GitHub ↗. Tạo 2 secret:
        Name: ICS_URLS
        Name: CAL_PASSPHRASE
      2. Mở Actions ↗ → Run workflow → đợi dấu ✅ (khoảng 1 phút).
      3. Bấm

      Mật khẩu đã được lưu sẵn trong app này. Thêm/bớt lịch sau này thì sửa secret ICS_URLS.

      🌐 Kết nối

      Lịch iCloud chặn trình duyệt tải trực tiếp, nên app thử lần lượt vài proxy công cộng. Proxy công cộng hay lỗi — nên dùng “Đồng bộ qua GitHub” ở trên.

      📥 Nhập file .ics

      Không dùng link được? Xuất lịch ra file .ics và nhập vào đây.
